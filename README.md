# Historical open-source snapshots

This private repository is being populated with actual pre-2021 source snapshots from the 100-project shortlist in **Find 50 Plus Projects**.

Each imported project has its own `project/NNN-name` branch containing the downloaded source files and original license notices. The `main` branch contains the index and machine-readable provenance. These are fresh snapshot imports, not forks or full upstream histories.

Only one selected core repository is included per project. Multi-repository ecosystems are not complete installations. Source dates refer to the selected upstream commit, not the new import commit.

Projects with unresolved historical licensing or unavailable source remain explicitly marked as pending; they are not silently replaced with different projects.

Import in progress. The completed index will record uploaded branches, checksums, license evidence, and any exclusions.
