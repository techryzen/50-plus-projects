# Historical open-source source collection

**60 projects in separate folders under `projects/`, all on the main branch.** These are actual downloaded pre-2021 source files, not submodules or external links. Choose **Code → Download ZIP** to download all folders together.

One core repository per project is included. Historical license notices are preserved. `.snapshot-info/` records provenance and supplies full reference license texts, without relicensing the files. Original upstream source files are unchanged. External dependencies and submodules are outside scope; applications have not been built or run.

The 60 smaller license-reviewed snapshots were selected from the original 100-project shortlist. Historical dates refer to selected upstream commits; old mirrors may not contain the globally latest pre-2021 release. Five original candidates remain excluded for unresolved source access or licensing. See the manifest for details of included projects.
